Friis Link Budget Calculator

WCM555 · Interactive tool comparing the free-space (Friis) model with the two-ray ground-reflection model

How to use

  1. Pick a preset or set transmitter power, antenna gains and frequency.
  2. Move the distance slider. The orange dot on the plot shows where you are.
  3. Set the antenna heights to see the two-ray interference pattern and the 1/d⁴ region.
  4. Compare received power with the receiver sensitivity to read the link margin.

Equations used

Wavelength and free-space path loss:

λ = c / f     FSPL(dB) = 20 log10(4πd / λ) = 20 log10(d) + 20 log10(f) − 147.55

Friis transmission equation (in dB):

Pr(dBm) = Pt(dBm) + Gt(dBi) + Gr(dBi) − FSPL(dB) − L(dB)

Two-ray model (direct path d₁ plus ground-reflected path d₂):

d₁ = √(d² + (ht − hr)²),   d₂ = √(d² + (ht + hr)²),   Δd = d₂ − d₁,   Δφ = 2πΔd / λ
Pr = Pt Gt Gr (λ / 4π)² · | 1/d₁ + Γ e−jΔφ / d₂ |²

Far-distance approximation (Γ = −1, d ≫ dc) and crossover distance:

Pr ≈ Pt Gt Gr ht² hr² / d⁴     dc = 4π ht hr / λ

Link margin and maximum free-space range:

Margin(dB) = Pr − S     dmax,FS = (λ / 4π) · 10(Pt + Gt + Gr − L − S) / 20

c = 3×10⁸ m/s. Gains are in linear form inside the two-ray formula and in dB in the Friis equation.

What to notice

  • Free space: doubling the distance costs 6 dB, and doubling the frequency also costs 6 dB.
  • Near the transmitter (d < dc): the direct and reflected waves go in and out of phase, so the two-ray curve swings above and below free space. It can be up to 6 dB stronger, and in the deep nulls it drops off sharply.
  • Far away (d > dc): the two waves almost cancel, so power falls at 40 dB/decade (1/d⁴) instead of 20 dB/decade. In this region the received power no longer depends on frequency.
  • Raising the antennas pushes dc further out and increases the far-distance received power by 20 log10(hthr).
